# Michelle-Essiet-s-repository-## Week 3: Variables, Data Types, Expressions and Input/Output

### Objectives
To understand how to use variables, data types, expressions, and input/output in Java.

### Programs
1. SimpleCalculator.java – Performs basic arithmetic operations.
2. AverageCalculator.java – Calculates the total and average of three scores.
3. ItemCost.java – Calculates the total cost of items purchased.

### How to Run
1. Compile the program using javac.
2. Run the program using java.

Example:
javac SimpleCalculator.java
java SimpleCalculator
